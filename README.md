## 买之前要知道的几个限制

价格之外，这几条直接影响使用体验，下单前最好过一遍：

1. **所有套餐都没有 DDoS 防护。** 建站被大流量攻击时 IP 会被临时空路由，一般 30 分钟左右恢复；反复被攻击可能直接被停止服务。需要高防的话，搬瓦工不合适。
2. **换 IP 要 8 美元一次。** IP 被墙想换，按次付费。
3. **退款有细则。** 30 天无理由退款只限新账户首次使用，且要求流量使用低于套餐限额的 10%、IP 没进过黑名单、账户没有违规和争议记录。退款后服务立即终止，数据、快照、备份全部删除。想试水的朋友，退款前别把流量跑超 10%。
4. **机房切换有门槛。** 只有 CN2 GIA-E 及以上的套餐才能切到 GIA、软银、9929 这些优化线路机房；香港、东京切不进去。每次切换机房消耗一次与硬盘等量的流量。
5. **性能中等。** 超售导致 CPU 性能一般，跑吃算力的任务要么上更高价位的套餐，要么另找对象。2025 年后的 Box 限量系列用了 EPYC 处理器，性能好不少，但上架与否全看官方。

## 哪些人没必要买搬瓦工

三类人可以省下这笔钱。一是对回国线路没要求的用户，访问以海外为主、或者只挂个脚本跑跑，同价位能买到配置更高的普通商家，没必要为用不上的线路付钱。二是需要 DDoS 防护的建站用户，前面说了，被攻击就断线。三是追求 CPU 性价比的用户，渲染、编译这类活，同样的预算在别处能买到强得多的配置。

搬瓦工的价值就集中在两件事上：线路和稳定性。你的需求恰好落在这两件事里，它就对得起价格；两样都不沾，它就只是贵。
